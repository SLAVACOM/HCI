# ЛР 1. Размер и запоминание цифр

Веб-тест для лабораторной работы по проектированию человеко-машинного интерфейса.

**Сайт:** https://slavacom.github.io/HCI/

## Гипотезы

1. Крупные арабские цифры (в 3 раза больше) запоминаются лучше, чем обычные, за один и тот же промежуток времени.
2. Размер сильнее влияет на пиктограммы, чем на арабские цифры: цифры распознаются как абстрактные символы, а в пиктограммах много деталей, которые сложнее запомнить.

## План тестирования

| Тест   | Вопросов | Что варьируется   | Что фиксировано                                              |
| ------ | -------- | ----------------- | ------------------------------------------------------------ |
| Тест 1 | 2        | размер (цифры)    | нотация — цифры, 6 наборов по 3–7 объектов вразнобой           |
| Тест 2 | 4        | размер × нотация  | одинаковые наборы для цифр и пиктограмм                       |

- **Тест 1:** вопрос 1 — 6 наборов крупных (×3) цифр, вопрос 2 — 6 наборов обычных цифр.
  Доказательство: сравнивается средний % правильно отмеченных цифр.
- **Тест 2** (наборы независимы от Теста 1): крупные цифры, мелкие цифры, крупные пиктограммы, мелкие пиктограммы — по 6 наборов.
  Доказательство: Δцифры = %(крупные цифры) − %(мелкие цифры), Δпиктограммы = %(крупные пикт.) − %(мелкие пикт.);
  гипотеза подтверждается, если Δпиктограммы заметно больше Δцифры.

### Как обеспечена сопоставимость

- Внутри одного теста все вопросы используют **одни и те же 6 наборов** (то же количество объектов и те же числа 1–9),
  меняется только порядок наборов и расположение на экране. Пиктограмма числа *k* — кость с *k* точками.
  Поэтому разница между вопросами объясняется только размером и нотацией.
- Количества объектов 3–7 распределены равномерно: каждое значение встречается примерно поровну.
- Крупный объект ровно в 3 раза больше обычного (на ПК 120 и 40 px), разброс по полю одинаковый.
- Время показа одинаковое для всех условий (по умолчанию 3 с), перед показом — точка фиксации 0,8 с.
- Ответ — выбор из кнопок 1–9 в той же нотации, 20 с.

### Статистика

- «% верно» — доля показанных объектов, которые участник правильно отметил (лишние отметки показываются отдельно).
- При 3 и более участниках — односторонний парный t-критерий Стьюдента по разностям каждого участника
  (гипотеза 1: крупные − обычные; гипотеза 2: Δпикт. − Δцифры). При 1–2 участниках — z-критерий для долей.
- Вывод: «подтверждается» при эффекте в нужную сторону и p < 0,05.

## Страницы

| Страница | Назначение |
| --- | --- |
| `lab_1/` | сам тест (Тест 1 + Тест 2, 36 раундов) |
| `lab_1/view.html` | результат участника: проверка гипотез, графики, таблица всех раундов; копирование текстом или ссылкой |
| `lab_1/summary.html` | сводка: вставьте ссылки/тексты всех участников — посчитает гипотезы по всем и по группам |
| `lab_1/generate.html` | генератор правдоподобных результатов для проверки страниц |

Результат хранится прямо в ссылке (`view.html#h1_…`), сервер не нужен.

### Параметры теста в адресе

| Параметр | По умолчанию | Смысл |
| --- | --- | --- |
| `t` | 3000 | время показа, мс |
| `a` | 20000 | время на ответ, мс |
| `min`, `max` | 3, 7 | количество объектов в наборе |
| `sets` | 6 | наборов в вопросе |
| `test` | оба | `1` или `2` — только один тест |
| `order` | фиксированный | `random` — перемешать порядок вопросов внутри теста |
| `g` | — | `control` — контрольная группа |

Пример: `lab_1/?test=1&t=2000`.
